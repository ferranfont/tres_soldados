# CLAUDE.md - AI Assistant Context

## Project Overview

**Tres Soldados** is an ES (E-mini S&P 500) futures data analysis and visualization toolkit. The project processes tick-level and minute-level market data, resamples to different timeframes, and generates interactive charts.

## Project Structure

```
tres_soldados/
├── data/                    # Market data CSV files
├── utils/                   # Data processing scripts
├── charts/                  # Generated HTML charts (gitignored)
├── plot_*.py               # Plotting modules
├── config.py               # Configuration
└── requirements.txt        # Dependencies (pandas, plotly, python-dotenv)
```

## Key Files

### Data Files (`data/`)
- `ES_near_tick_data_27_jul_2025.csv` - Tick data (~547K records, European format: `;` separator, `,` decimal)
- `es_1min_data_2015_2025.csv` - 1-minute data (2015-2025, ~3.5M bars)
- `es_1min_data_2023_03_01.csv` - Single day extract (generated by scripts)

### Processing Scripts (`utils/`)
- `clean_data_and_format_tick_data.py` - Processes tick data → 1-minute candlestick chart
- `clean_data_minut_format_all_dataframe.py` - Resamples 10 years minute data → daily line chart
- `clean_data_one_day_data.py` - Extracts single day from full dataset → candlestick chart

### Plotting Modules
- `plot_tick_data.py` - Candlestick charts for tick/second data
- `plot_minute_data.py` - Candlestick charts for minute data (intraday)
- `plot_chart_volume.py` - Line charts for daily data (long-term trends)

### Configuration
- `config.py` - Centralized settings (data paths, chart dimensions, OHLCV aggregation)

## Data Flow

```
Tick Data (European format)
    ↓ clean_data_and_format_tick_data.py
1-Minute Candlestick Chart

1-Minute Data (2015-2025)
    ↓ clean_data_minut_format_all_dataframe.py
Daily Line Chart (10 years)

1-Minute Data (2015-2025)
    ↓ clean_data_one_day_data.py
Single Day CSV + Candlestick Chart
```

## Important Notes

### Data Formats
- **Tick data**: European CSV (`;` separator, `,` decimal, `DD/MM/YYYY HH:MM` datetime)
- **Minute data**: Standard CSV (`,` separator, `.` decimal, ISO datetime with UTC)

### Chart Types
- **Candlestick**: Used for tick/minute intraday data (shows OHLC bars)
- **Line**: Used for daily/long-term data (shows close prices only)

### Timezone Handling
- All datetime data is stored/processed in **UTC timezone**
- Use `pd.to_datetime(..., utc=True)` for consistency

### Configuration Variables (`config.py`)
- `DATA_DIR` - Path to data folder (default: `./data`)
- `SYMBOL` - Trading symbol (default: `'ES'`)
- `CHART_WIDTH`, `CHART_HEIGHT` - Chart dimensions
- `OHLCV_AGGREGATION` - Rules for resampling OHLCV data

## Common Tasks

### To plot tick data:
```bash
python utils/clean_data_and_format_tick_data.py
```

### To plot 10 years daily data:
```bash
python utils/clean_data_minut_format_all_dataframe.py
```

### To extract and plot a specific day:
1. Edit `TARGET_DATE` in `utils/clean_data_one_day_data.py`
2. Run: `python utils/clean_data_one_day_data.py`

### To run standalone plotting:
```bash
python plot_chart_volume.py    # Daily line chart
python plot_minute_data.py     # Minute candlestick chart
python plot_tick_data.py       # Tick candlestick chart
```
